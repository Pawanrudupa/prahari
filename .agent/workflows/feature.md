# Workflow: feature
Input: feature name + roadmap phase.
1. Read AGENTS.md, relevant docs, and only the code files you need.
2. Write a short plan: files, data model/API changes, tests, UI states (empty/loading/error).
3. Implement with tests. Update docs/05 if API/data changed.
4. Run lint, types, tests; verify UI in the browser.
5. Summarize changes and any deviations from the docs.
